## Subject Overview

- **Web Systems 31268** is an introduction to Information Technology
- It is a **core foundation subject** at UTS for IT degrees
- Uses the **web as a case study** for IT concepts
- Adopts an **integrated teaching and learning model**
- Skills learned here are **prerequisite knowledge** for future IT subjects

- Networking fundamentals
- Security awareness
- Data management principles
